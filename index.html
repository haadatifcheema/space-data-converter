IGCSE Computer Science: How JavaScript Conversions Work

// 1. Converting a number to Binary (Base-2) let decimalNum = 42; let binaryString = decimalNum.toString(2); // .toString(2) tells JavaScript to convert the number into Base-2 (binary digits 0 and 1). // Result: "101010" (42 in binary is 32 + 8 + 2) let hexString = decimalNum.toString(16); // .toString(16) converts the number into Base-16 (Hexadecimal: 0-9 and A-F). // Result: "2a" (2 × 16 + 10) // 2. Converting back from Binary/Hex to Denary let denaryVal = parseInt("101010", 2); // parseInt(string, base) parses a string in the specified base back into a normal integer (Denary).
In IGCSE Computer Science, understanding number bases is crucial for storing spacecraft data efficiently (Hexadecimal is often used to represent memory addresses and binary streams compactly).
